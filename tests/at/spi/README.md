# AT-SPI expected names

`expected_names.yaml` lists the accessibility anchors (`Accessible.id` and
`DccObject.accessibleId`) found in the QML sources. The AT-SPI test suite uses
it as the expected-name set.

The file is generated by an external scanner; the generator is not part of
this repository. The scanner records:

- `accessible_id`: the identifying string literal of the anchor binding.
  Dynamic anchors are recorded as the static prefix ending in `_`, for example
  `DeviceListView_DeviceCheck_` for `"DeviceListView_DeviceCheck_" + index`.
- `line`: the line of the `Accessible.id` / `accessibleId` binding.
- `id`: the QML object id, when the scanner can attribute it.

Regenerate the file after changing anchors and keep it in sync with the
current source.
